# NEAT-Powered AI Agents through the game of Pong
Training &amp; Dueling Programs for NEAT-Python optimized AI Agents through Scaling Difficulty Environments

**Instructions:**

```pong_power.py``` is the base pong game version without AI agents & NEAT Algorithm.

```pong_final_power_up.py``` is the NEAT-AI training program that takes parameters from ```config-final_power_up.txt```.

```duel_ai``` is a Vibe Coded Program with Google's Gemini, which allows to AI-agents through ```.pkl``` files to go up against each other. Both NEAT-networks run, but don't mutate.

**TO DUEL AI**:

1. install dependencies through ```requirements.txt```.

2. Pass two ```.pkl``` files on Line XX on the ```duel_ai``` program.

**TO TRAIN AI**

1. Set Fitness & Evolutionary Parameteres on ```config-final_power_up.txt```.
   
3. Configure ```pong_final_power_up.py``` accordingly, then run the program. You may press the "F" key to pass 1000 frames into the program, speeding up the process. Then you can press "S" to return to 60 FPS.
